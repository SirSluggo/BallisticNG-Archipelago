# AI disclosure

AI was used extensively in this implementation. ChatGPT and Codex generated and revised substantial portions of the Archipelago world, Python bridge/client, C# mod, save-isolation integration, tests, packaging scripts and documentation. They also assisted with design discussions, debugging and analysis of user-supplied logs and inspected game APIs. This project should not be described as mostly human-written code with occasional AI assistance.

The project owner directed features and design, installed builds, and performed repeated live gameplay and integration tests. These included event checks, item delivery, access locks, hints, cosmetics, traps, multiworld interaction, save persistence, save isolation, forced-shutdown recovery and a fresh installation.

Code inspection and automated checks were largely AI-assisted. The project has not received an independent human code review. Passing tests and live playtesting do not establish that every code path is correct or that the project satisfies Archipelago community publication requirements.

The project owner takes responsibility for code that they choose to publish and maintain. This disclosure does not transfer that responsibility to an AI tool. It should be updated if the implementation or review history changes.

No AI image generation was used for this project. Art Appreciation Trap loads concept art from the installed game; those art files are not bundled.
